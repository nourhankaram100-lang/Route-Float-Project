🌊 Route Float Project

📝 Description

This project was created as part of my Route Academy training.
It demonstrates how to build a complete webpage layout using classic CSS techniques like float, clear, display, and inline-block.
It was one of my early practical tasks to understand how these properties work together before moving to Flexbox and Grid.

💻 Technologies Used

HTML5
CSS3

⚙️ Features

Layout built using float and inline-block (not responsive)

Demonstrates float, clear, and basic positioning techniques

Organized page sections (header, content, footer)

Intended as a practice task for classic CSS layout methods

🚧 Notes

The design is not fully responsive, as it was mainly for practicing float-based layouts.
